## Typography

Actual rendered audition: [style-guide.html](style-guide.html), with the same German
project names and coverage counts in system grotesk, serif and monospace. Selected
Helvetica Neue/Arial/system sans for scan speed and compact panels, Georgia for retained
reading roles, UI monospace for identifiers and canonical source excerpts. These fonts
are used only if installed; no binaries are redistributed.

Additional candidates researched, not installed or visually auditioned:
[IBM Plex Sans metadata](https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexsans/METADATA.pb)
and [OFL](https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexsans/OFL.txt);
[Instrument Serif metadata](https://raw.githubusercontent.com/google/fonts/main/ofl/instrumentserif/METADATA.pb)
and [OFL](https://github.com/google/fonts/blob/main/ofl/instrumentserif/OFL.txt).
Both support Latin-ext. Plex would be the first self-hosted-font follow-up if platform
consistency becomes important. No download is necessary for the selected direction.

## Reference lock

City Desk: (1) actual geography dominates, (2) a stable index leads to substantial
entries, (3) documentary precision survives expressive presentation. Secondary inputs:
The Futur for task-based hierarchy; existing atlas marker language for identity;
Lumos for native token organization. Reject stock construction photography, invented
progress, generic marketing sections and decorative serif word swaps. This is an
original design inference from references and project constraints, not a replica.
