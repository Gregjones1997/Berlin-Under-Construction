# Controlled German–English domain glossary

**Status:** Discovery seed rows; not yet project-owner confirmed
**Last updated:** 2026-08-06

German is canonical. The English column is a proposed display mapping, not a
replacement for the source wording. Every use must retain the object, phase,
date precision and evidence span. Rows below were encountered during the named
candidate discovery pass recorded in
[`research/candidate-discovery-trail.md`](research/candidate-discovery-trail.md).
This seed does not complete the Phase 1 controlled-glossary checklist item.

## Milestones, phases and status terms

| German source term | Proposed display mapping | Distinction to preserve |
| --- | --- | --- |
| `Baubeginn` | construction start | Not planning start, site setup or opening |
| `Baustart` | construction start | Often informal; retain the source's object |
| `Spatenstich` | groundbreaking | Ceremonial milestone; not proof that main works began |
| `Bauarbeiten` | construction works | Activity, not itself a milestone |
| `Bauausführung` | construction execution | Delivery stage, not completion |
| `Baumaßnahme` | construction measure | Scope noun; not automatically a whole project |
| `Bauabschnitt` | construction phase | Retain phase number and boundary |
| `erster Bauabschnitt` | first construction phase | Never present as whole-project scope |
| `Hauptmaßnahmen` | main works | Distinct from preparatory works |
| `bauvorbereitende Maßnahmen` | preparatory works | Not construction completion; may precede main works |
| `Baufeldfreimachung` | site clearance | Preparatory milestone |
| `Baufeld` | construction plot / development parcel | Geographic/phase unit, not the whole development |
| `Bauzeit` | construction period | A duration or range; not necessarily an end milestone |
| `Voraussichtliche Bauzeit` | expected construction period | Preserve uncertainty and both endpoints |
| `Bauende` | construction end | Construction milestone; not necessarily handover/opening |
| `Fertigstellung` | completion | Retain what is completed and date precision |
| `vollständige Fertigstellung` | full completion | Stronger than a phase or partial completion |
| `bauliche Fertigstellung` | physical construction completion | Equipment, move and operation may follow |
| `geplante Fertigstellung` | planned completion | Preserve planning status |
| `Fertigstellungstermin` | completion date | May be expressly unreliable or unknown |
| `Gesamtfertigstellung` | overall completion | Distinct from phase completion or traffic release |
| `Abschluss des ersten Bauabschnitts` | completion of the first construction phase | Phase-only milestone |
| `Baumaßnahme abgeschlossen` | construction measure completed | Retain the exact measure boundary |
| `Bauabnahme` | construction acceptance | Acceptance milestone; not automatically public opening |
| `Übergabe` | handover | State the recipient only when source-supported |
| `Übergabe an den Bezirk` | handover to the district | Distinct from construction completion and opening |
| `Eröffnung` | opening | Public/institutional opening; not necessarily construction end |
| `Umzug` | move | Operational transition after building completion |
| `Aufnahme des Unterrichtsbetriebes` | start of teaching operations | School service-start milestone |
| `Inbetriebnahme` | commissioning / entry into operation | Distinct from physical completion and public opening |
| `Verkehrsfreigabe` | opening to traffic | Traffic milestone; not automatically project completion |
| `Regionalzüge werden dort ab … halten` | regional trains will call there from … | Service-start wording; not necessarily physical completion |
| `Bezugsfertigkeit` | ready for occupancy | Distinct from actual occupancy |
| `bezogen` | occupied / moved into | Actual occupancy wording |
| `Planreife` | planning maturity | Planning milestone, not construction end |
| `Bebauungsplanverfahren` | development-plan procedure | Statutory planning process |
| `Bauleitplanung` | land-use planning | Planning family, not construction |
| `Rahmenplan` | framework plan | Planning document |
| `Werkstattverfahren` | workshop planning process | Participatory/design process, not construction |
| `Vorbereitende Untersuchungen` | preparatory investigations | Pre-development/planning stage |
| `Realisierungswettbewerb` | design competition for implementation | Competition stage; implementation is not guaranteed |
| `Erschließung` | site servicing / infrastructure provision | May be a separate project from building construction |
| `Projektzeitraum` | project period | Endpoint is not automatically a completion milestone |
| `Laufzeit` | duration / project period | Retain whether it describes planning, funding or works |
| `Gesamtmaßnahme` | overall measure | Scope-control term; verify included phases |

## Financial, budget and procurement-context terms

| German source term | Proposed display mapping | Distinction to preserve |
| --- | --- | --- |
| `Kosten` | costs | Untyped amount; do not normalize without measure context |
| `Gesamtkosten` | total costs | Retain scope, tax, price basis and as-of date |
| `Gesamtbausumme` | total construction sum | Construction-only scope may differ from total project cost |
| `voraussichtliche Gesamtkosten` | expected total costs | Forecast, not actual expenditure or final cost |
| `Planungskosten` | planning costs | Separate from construction costs |
| `Baukosten` | construction costs | Separate from planning, land, equipment and finance |
| `Investitionsvolumen` | investment volume | Not automatically a budget or final cost |
| `Investitionen` | investments | Plural/aggregate unless project scope is explicit |
| `Investitionsmittel` | investment funds | Funding availability, not expenditure |
| `Investitionsrahmen` | investment envelope | Authorization/envelope, not actual cost |
| `Finanzierung` | financing | Funding arrangement, not project cost |
| `Finanzierung aus Haushalt Berlin` | financing from the Berlin budget | Funding source; retain budget reference |
| `Finanzierungsvereinbarung` | financing agreement | Agreement, not proof of payment |
| `Ergänzungsunterlage zur Finanzierung` | supplementary financing document | Document type, not a financial measure |
| `haushalterische Grundlage` | budgetary basis | Authorization context |
| `finanziert aus dem Plätzeprogramm` | financed from the public-squares programme | Funding source, not total project cost |
| `Finanzierungslücke` | funding gap | Gap against a stated need; retain comparison basis |
| `GRW-Mittel` | GRW funds | Funding-programme money; retain programme and year |
| `Zuschüsse` | grants / subsidies | Funding contribution, not total cost |
| `Ausgaben` | expenditure | Retain planned versus actual and period |
| `Verpflichtungsermächtigung` | commitment authorization | Authority to enter future commitments; not expenditure |
| `Einzelplan` | departmental budget | Budget hierarchy term |
| `Kapitel` | budget chapter | Budget hierarchy term |
| `Nachtragsleistungen` | additional contract services | Do not infer a project cost overrun |
| `Baupreisindex` | construction price index | Price-adjustment context, not an amount itself |
| `geschätzt` | estimated | Qualifier; retain estimate basis and as-of date |
| `Realisierungsverträge` | implementation agreements | Contract family; not an award value |
| `Einbringungsverträge` | contribution/transfer agreements | Delivery/legal instrument; do not infer ownership or value |
| `Investorenprojekt` | investor-led project | Delivery context, not a documented organization role by itself |
