# 80-second portfolio walkthrough

Use the [public atlas](https://berlin-under-construction.vercel.app/).
This is a timed script and click guide, not a prerecorded video. Allow 80 seconds
at a conversational pace, including pauses for navigation. Load the atlas before
starting; rehearse once on the presenting device. On mobile, scroll inside the
selected project panel to reach the full overview and its evidence.

| Time | Show / action | Say |
| --- | --- | --- |
| 0–15s | Atlas overview, then select **Europaplatz Süd** from the project list. | “I designed Berlin, Under Construction to keep the evidence behind construction claims visible. There are 150 basic register listings and three reviewed dossiers. The architecture is orientation, not live construction progress.” |
| 15–30s | Read the compact dates; scroll to **Full project overview** and open it. | “Europaplatz separates an announced start from planned completion. Older source statements remain in its history, and conflicting financing statements remain unresolved. A polished card should not erase those differences.” |
| 30–45s | In the overview, expand **Evidence** under the start statement containing **2. Februar 2026**, then follow **Original source**. | “This German passage supports the displayed start statement. One link opens the authority’s original publication, dated January 26. Checking that passage does not establish what happened on site afterward.” |
| 45–60s | Browser Back, then **Back to previous view**. Open **Project index**, then its **C-019** withheld-location link. | “The static index preserves another route to the evidence. This energy project remains accessible, but its location is withheld with a reason instead of an invented map pin.” |
| 60–80s | Point to **Translation unverified** on the energy dossier, then **How it works**. | “I set product direction, visual priorities and publication boundaries. AI assisted research, extraction proposals, implementation and tests. Independent German glossary review remains unfinished. This demonstrates an inspectable workflow, without claiming extraction accuracy or time savings.” |
